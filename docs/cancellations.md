# Отмены и mock-возвраты

| Запрос | Правило |
| --- | --- |
| `POST /orders/{id}/cancel` | Владелец отменяет весь заказ до начала события |
| `POST /events/{id}/cancel` | Только ADMIN отменяет DRAFT/PUBLISHED событие |

PENDING-заказ становится CANCELLED, активная бронь — EXPIRED. Для PAID-заказа
возвращается вся сумма в рамках mock-системы: статус заказа и платежа REFUNDED,
время возврата сохраняется, билеты становятся CANCELLED. Реального списания/возврата нет.
Если хотя бы один билет USED, покупатель не может отменить заказ.
Повтор отмены возвращает текущее состояние без повторного возврата и аудита.
Повтор оплаты с исходным ключом после возврата показывает REFUNDED и отменённые билеты.

Освобождённые места доступны для новой покупки только у будущего PUBLISHED-события.
Новая покупка создаёт отдельные бронь, заказ и билеты; история прежних сохраняется.

Отмена события администратором атомарно закрывает активные брони, отменяет PENDING,
возвращает все PAID-заказы и аннулирует их билеты, в том числе USED. FINISHED-событие
не отменяется. Общая блокировка события согласует отмену с оплатой и сканированием:
после отмены не остаётся действительных билетов или успешной невозвращённой оплаты.
