# Каталог и управление ресурсами

| Действие | API (ORGANIZER — свои ресурсы, ADMIN — все) |
| --- | --- |
| Площадка | `POST /venues`, `PATCH /venues/{id}`, `DELETE /venues/{id}` |
| Секции | `GET/POST /venues/{id}/sections`, `PATCH/DELETE /venues/{id}/sections/{section_id}` |
| Места | `GET/POST /venues/{id}/sections/{section_id}/seats`, `PATCH/DELETE /venues/{id}/seats/{seat_id}` |
| Событие | `POST /events`, `PATCH /events/{id}`, `DELETE /events/{id}` |
| Тарифы | `POST /events/{id}/ticket-types`, `PATCH/DELETE /events/{id}/ticket-types/{tariff_id}` |
| Чтение тарифов | `GET /organizer/events/{id}/ticket-types` |
| Назначение тарифа месту | `PUT /events/{id}/seats/{seat_id}/tariff` с `ticket_type_id` |

Порядок: площадка → секция → места (JSON-массив, 1–500 за запрос) → событие
со статусом DRAFT → тарифы → `PATCH /events/{id}` с `{"status":"PUBLISHED"}`.
Даты передаются с часовым поясом; деньги — десятичной строкой, например `"1200.50"` KZT.
Владельца определяет сервер по площадке; клиент не может передать другую роль или владельца.

Первый тариф секции автоматически назначается её существующим местам. Для другого
тарифа используется явное назначение. Публикация добавляет новые места с единственным
тарифом секции; если выбор неоднозначен или тариф отсутствует, возвращает `409`.
Опубликованный зал, цены и дата фиксируются. Заголовок и описание события можно исправить.
Площадка с любым событием после DRAFT больше не меняет схему. Для новой схемы создаётся
новая площадка. Удалять можно только черновики без истории бронирования.
Перевод в FINISHED разрешён для PUBLISHED после начала события.

| Публичный маршрут | Результат |
| --- | --- |
| `GET /events` | Будущие PUBLISHED; `city`, `category`, `date_from`, `date_to`, `min_price`, `max_price`, `q` |
| `GET /events/{id}` | Опубликованное будущее событие |
| `GET /events/{id}/seats` | Места, секции, тарифы, цены, статусы available/reserved/sold |

Все фильтры комбинируются. Минимум и максимум цены должны совпадать для одного
фактически назначенного тарифа. Поиск `q` — подстрока заголовка без учёта регистра.
Пагинация каталога: `limit=50` (1–100), `offset=0`; схема мест: `limit=500` (1–1000).
Истёкшая бронь не удерживает место даже до фоновой очистки. VALID и USED считаются sold.
Неизвестный и недоступный по владельцу ресурс возвращают одинаковый `404`.
